# Formative Java

Tâches à accomplir :

- lisez le code avec attention et comprenez-le
- exécutez le code et observez la sortie console
- mettez un point d'arrêt là où le OK est affiché et lancez le mode débogage
- lorsque le point d'arrêt est atteint, observez les variables existantes à ce moment-là ainsi que leur contenu. Est-ce que la variable `i` existe ?
